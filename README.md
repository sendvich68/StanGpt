# STAN GPT 🤖🦀

Локальный искусственный интеллект на языке **Rust**, который работает прямо в терминале. 
Он не требует мощного железа и работает офлайн (кроме поиска в Википедии).

## Возможности
- 🧠 **Обучаемая база знаний** (вопрос-ответ).
- 📖 **Библиотека слов** (словарь с местоимениями).
- 🌍 **Переводчик** (двусторонний).
- 🧮 **Математика** (решает примеры вроде `2 + 2 * 10`).
- 🔎 **Поиск в Википедии** (если не знает ответа).
- 🎨 **Пиксельный арт** (рисует картинки по описанию).
- ✏️ **Редактирование** базы знаний на лету.

## Как запустить
1. Установите Rust: `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`
2. Клонируйте репозиторий: `git clone https://github.com/ВАШ_ЛОГИН/stangpt.git`
3. Перейдите в папку: `cd stangpt`
4. Запустите: `cargo run --release`

## Команды
- `/1` — Обучить (вопрос/ответ)
- `/2` — Добавить слово
- `/3` — Исправить слово
- `/4` — Добавить перевод
- `/5` — Перевести слово
- `/6` — Составить текст
- `/7` — Показать знания
- `/8` — Показать слова
- `/9` — Помощь
- `/10` — Сгенерировать арт
- `/11` — Исправить вопрос/ответ
- `/0` — Выход
